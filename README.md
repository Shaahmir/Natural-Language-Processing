# Natural Language Processing Algorithms in Python

A comprehensive **Natural Language Processing** repository built with **Python** and **NLTK, spaCy, scikit-learn, Gensim, TensorFlow, and Keras**, covering the complete natural language processing workflow from **Text Normalization** to **Question Answering Chatbots**. This repository contains well-structured Jupyter notebooks implementing popular **Text Normalization**, **Vectorization Methods**, **Word Embedding Methods**, **Recurrent Neural Networks**, **Topic Modelling**, **TextBlob**, and **NLP Projects**, making it an excellent resource for learning, interview preparation, and portfolio projects.

# Installation

Clone the repository:

```bash
git clone https://github.com/shaahmir/Natural-Language-Processing-Python.git
```

Install the required dependencies:

```bash
pip install numpy pandas matplotlib nltk spacy scikit-learn gensim tensorflow keras textblob jupyter
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open any notebook and run the cells to explore the algorithm.
